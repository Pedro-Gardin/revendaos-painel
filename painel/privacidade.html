Política de Privacidade

Última atualização: 29/08/2026

Esta Política de Privacidade descreve como o RevendaOS ("nós", "sistema", "plataforma") coleta, usa, armazena e protege os dados pessoais tratados através da plataforma, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD).

Ao utilizar o RevendaOS, você concorda com os termos descritos abaixo.

1. Quem é o responsável pelo tratamento dos dados

O RevendaOS é operado por Pedro Henrique Cherubini Gardin, CPF 04261414074, com contato através do e-mail pedrohenriquecherubinigardin@gmail.com.

Enquanto o RevendaOS opera como pessoa física, este responsável atua como Controlador dos dados tratados na plataforma, nos termos da LGPD.

2. Quais dados coletamos

2.1. Dados da revenda (nosso cliente direto)

Ao criar uma conta no RevendaOS, coletamos:

  • Nome da revenda
  • E-mail e senha de acesso (armazenados de forma segura pelo Firebase Authentication, com senha criptografada — nunca temos acesso à senha em texto puro)
  • Identificador único (slug) escolhido para a revenda

2.2. Dados de usuários internos da revenda

Quando o dono de uma revenda convida membros da equipe (vendedor, financeiro, etc.), coletamos nome, e-mail e o cargo/função atribuído dentro da plataforma.

2.3. Dados de clientes finais (CRM)

Quando uma revenda cadastra um lead/cliente interessado em um veículo, coletamos, a pedido e sob responsabilidade da revenda: nome do cliente, telefone/WhatsApp, interesse declarado e observações registradas pelo vendedor.

Importante: esses dados são inseridos pelas revendas clientes, que atuam como Operadoras desses dados perante seus próprios clientes finais. A revenda é responsável por garantir que possui base legal e consentimento adequados para cadastrar esses dados no sistema.

2.4. Dados de veículos e financeiros

Informações sobre o estoque de veículos, preços, custos, lançamentos financeiros e comissões cadastradas pela revenda. Esses dados são de natureza comercial, não pessoal, mas ficam armazenados com o mesmo nível de proteção.

2.5. Fotos de veículos

Enviadas pelas revendas para exibição pública no site de vitrine. Armazenadas através do serviço Cloudinary.

2.6. Dados de navegação

Como em qualquer aplicação web, podem ser coletados automaticamente dados técnicos básicos (endereço IP, tipo de navegador) pelos provedores de infraestrutura (Google Firebase, Vercel) para fins de segurança e funcionamento do serviço.

3. Para que usamos esses dados

  • Viabilizar o funcionamento do painel de gestão e do site público de cada revenda
  • Autenticar usuários e controlar permissões de acesso
  • Exibir o estoque de veículos no site público da revenda
  • Gerar relatórios financeiros e de metas para a própria revenda
  • Comunicação relacionada ao funcionamento da conta (ex: recuperação de senha)
  • Cumprimento de obrigações legais, quando aplicável

Não utilizamos os dados para venda a terceiros, nem para publicidade direcionada fora da plataforma.

4. Onde os dados ficam armazenados

  • Banco de dados e autenticação: Google Firebase (Firestore/Authentication), com banco de dados hospedado na região São Paulo, Brasil (southamerica-east1).
  • Fotos de veículos: Cloudinary, serviço de hospedagem de imagens (infraestrutura internacional).
  • Hospedagem do site e painel: Vercel.

5. Compartilhamento de dados

Não compartilhamos dados pessoais com terceiros para fins comerciais. Os dados podem ser acessados pelos provedores de infraestrutura acima (Google Firebase, Cloudinary, Vercel), estritamente para viabilizar o funcionamento técnico da plataforma. Podemos divulgar dados caso exigido por ordem judicial ou autoridade competente.

6. Isolamento entre revendas

Cada revenda cadastrada no RevendaOS opera em um ambiente isolado ("organização"). As regras de segurança do banco de dados impedem que uma revenda acesse dados de outra revenda. Dentro de cada revenda, o acesso aos dados é ainda controlado por cargo (dono, vendedor, financeiro, visualizador), conforme configurado pelo dono da conta.

7. Seus direitos como titular de dados

Conforme a LGPD, você tem direito a: confirmar a existência de tratamento; acessar seus dados; corrigir dados incompletos, inexatos ou desatualizados; solicitar anonimização, bloqueio ou eliminação de dados desnecessários; solicitar a portabilidade dos dados; solicitar a exclusão dos dados tratados com base no consentimento; e revogar o consentimento a qualquer momento.

Para exercer qualquer um desses direitos, entre em contato através de pedrohenriquecherubinigardin@gmail.com.

8. Retenção e exclusão de dados

Os dados são mantidos enquanto a conta da revenda estiver ativa. Caso o dono da revenda solicite o encerramento da conta, os dados poderão ser excluídos em até 30 dias , exceto quando houver obrigação legal de retenção por prazo maior.

9. Segurança dos dados

Adotamos medidas técnicas para proteger os dados armazenados, incluindo autenticação obrigatória para acesso ao painel, regras de segurança no banco de dados que isolam os dados por revenda e por cargo de usuário, comunicação criptografada (HTTPS), e validação de dados para prevenir ataques comuns (como XSS).

Nenhum sistema é 100% livre de falhas. Em caso de incidente de segurança que possa afetar dados pessoais, comunicaremos os titulares e a Autoridade Nacional de Proteção de Dados (ANPD) conforme exigido por lei.

10. Alterações nesta política

Esta política pode ser atualizada periodicamente. Alterações relevantes serão comunicadas através do painel ou por e-mail cadastrado.
